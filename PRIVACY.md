## What this app is

A quiet reading room for seventeen classical homoeopathic repertories — 271,421 rubrics and 744,394 graded remedy links, read straight from the open JSON library. No…

## What it collects

**Nothing.** No analytics, no telemetry, no crash reporting, no fingerprinting, no advertising identifier and
no email capture.

It **downloads public data** — the repertory catalogue and text — from GitHub (`raw.githubusercontent.com`) and jsDelivr (`cdn.jsdelivr.net`). Those requests fetch published data and carry nothing about you beyond what any web request carries. Nothing you type or bookmark is sent to either service.

Those two hosts see your IP address when the data is fetched, as any download does. If that matters to you,
use a build that ships the data locally instead.

## What is stored on your device

Whatever the app remembers between visits stays on this device. Clearing the app's stored data erases it.

## Links that leave the app

Documentation and support pages contain ordinary links. Opening one takes you to that site, with its own
privacy policy; the app loads nothing from it.

## Erasing

Clear the app's stored data, or delete the app itself. Nothing is held anywhere else, so there is no other
copy to ask us to remove.

## Changes

If a future version ever adds a request that carries your data, this file changes in the same commit.
